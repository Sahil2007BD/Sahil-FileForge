**# 🚀 SahilPDF Studio

A simple and fast PDF tool built by Sahil.

## ✨ Features

* 📄 Merge multiple PDFs
* ✂️ Split PDF files
* ✍️ Add signature (coming soon)
* ⚡ Fast and easy to use

## 🛠️ Tech Stack

* Frontend: HTML, CSS, JavaScript
* Backend: Node.js, Express
* PDF Processing: pdf-lib

* Signature drawing
